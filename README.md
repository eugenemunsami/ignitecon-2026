# IgniteCon 2026

The Unconventional Business Bootcamp — event landing page.

**Live:** [ignitecon.uca.africa](https://ignitecon.uca.africa) *(once DNS is pointed)*

**Dates:** 28 – 31 October 2026  
**Venue:** 26 Degrees South Hotel, Muldersdrift  
**Cohort:** 20 growth-stage SA founders

## Deployment

Auto-deploys to Netlify on every push to `main`.

- Forms: hosted on [Jotform](https://www.jotform.com), embedded via iframe in modals
- Assets: served from `/assets/` with long cache
- Fonts: Google Fonts (Bebas Neue + Space Grotesk + JetBrains Mono)

## Editing

Pushing to `main` triggers a redeploy. Small copy changes can be made directly on GitHub.
